# Burger Craft

Aplicativo mobile de demonstração para uma hamburgueria artesanal, feito com Expo e React Native. A tela apresenta os hambúrgueres do cardápio e permite informar um nome para simular o envio de um pedido.

## Requisitos

- Node.js
- npm

## Instalação

```bash
npm install
```

## Executar

```bash
npm start
```

Também é possível iniciar diretamente em uma plataforma:

```bash
npm run android
npm run ios
npm run web
```

## Tecnologias

- Expo
- React Native
- TypeScript
- Fonte Outfit
